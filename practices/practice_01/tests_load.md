# Нагрузочные проверки

| Сценарий | Нагрузка и длительность | Допустимый предел | Что измеряем | Подтверждение |
|---|---|---|---|---|
| Одиночный запрос | 1 RPS, 1 мин | p95 ≤ 12 с (с учётом 10 с таймаута LLM по `REL-1`) | Время ответа `POST /api/reviews` | Locust: `single_user` |
| Средняя нагрузка | 10 RPS, 5 мин | p95 ≤ 12 с, ошибок ≤ 1% | Время ответа и доля ошибок | Locust: `steady_load` |
| Пиковая нагрузка | 50 RPS, 1 мин | p95 ≤ 15 с, ошибок ≤ 5% | Устойчивость при пике | Locust: `spike` |
| Большой diff (граничный по `API-1`) | 5 RPS, diff ровно 20 000 символов | p95 ≤ 12 с | Время обработки максимально допустимого PR | Locust: `large_diff_boundary` |
| diff сверх лимита | 5 RPS, diff 20 001 символ | Ответ ≤ 100 мс, HTTP 413 | Скорость отказа без вызова LLM | Locust: `too_large_diff` |
| Медленный LLM | 5 RPS, мок LLM с задержкой 15 с | Timeout 10 с (`REL-1`), ошибок ≤ 10% | Срабатывание таймаута и корректность контролируемого ответа | Locust + мок LLM: `slow_llm` |
| Отказ LLM | 5 RPS, мок LLM бросает `RuntimeError` | Ошибок ≤ 10%, ответ не 500 | Контролируемый ответ при отказе LLM | Locust + мок LLM: `llm_error` |

## Ожидаемые пределы

| Параметр | Значение |
|---|---:|
| Максимальный размер diff | 20 000 символов (`API-1`) |
| Timeout внешнего LLM | 10 с (`REL-1`) |
| Максимальное время ответа (p95) | 12 с |
| Пропускная способность | 10 RPS |
| Допустимая доля ошибок | 1% |

Точки отказа: rate limit у LLM-провайдера, конкурентная запись в `results/`, отсутствие лимита на размер diff (потенциальный DoS — закрывается `API-1`), утечка содержимого diff в логи (`OBS-1`).
